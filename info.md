# Shabbat Clock Integration

A powerful 24-hour visual timer with automatic entity control for Home Assistant.

> **Fork notice:** Fork of [davidss20/home-assistant-24h-timer-integration](https://github.com/davidss20/home-assistant-24h-timer-integration) by David S, maintained by [@shimon88](https://github.com/shimon88) under the MIT License.

## ✨ Key Features

- 🕐 **24-Hour Visual Timer** - Circular timer with half-hour precision
- 🎯 **Automatic Entity Control** - Control lights, switches, fans, and more
- 🏠 **Smart Activation Conditions** - Timer activates only when conditions are met (home presence, custom sensors)
- 🌍 **Multi-Language Support** - Hebrew, English, German, Spanish, French, Italian, Dutch, Polish
- 📊 **Real-Time Status** - Visual indicators for system and entity status
- 🔄 **Event-Driven** - Instant response to condition changes (no polling delays)
- 🎨 **Beautiful UI** - Modern Lovelace card with RTL support

## 🚀 Quick Start

1. **Install** via HACS
2. **Restart** Home Assistant
3. **Add Integration**: Settings → Devices & Services → Add Integration → Shabbat Clock
4. **Add Card**: Dashboard → Add Card → Shabbat Clock Card

## 📸 Preview

The card displays a 24-hour circular timer where you can:
- Click segments to activate/deactivate time slots
- See current time highlighted in red
- View entity status in the center circle
- Monitor system activation status

## 🎯 Perfect For

- Water heater schedules
- Smart lighting automation
- Garden irrigation timers
- HVAC scheduling
- Any time-based automation

## 🔧 Configuration

Simple configuration flow:
1. Name your timer
2. Select entities to control (optional)
3. Set activation conditions (optional)
4. Choose condition logic (OR/AND)
